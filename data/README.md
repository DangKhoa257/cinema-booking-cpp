# Dữ liệu demo

Các file `.txt` chỉ minh họa định dạng dự kiến trong `docs/API_CONTRACT.md`; skeleton chưa đọc/ghi chúng. Mỗi dòng là một record phân cách bằng `|`; dòng bắt đầu `#` là chú thích. Tất cả tên là dữ liệu hư cấu. Không thêm mật khẩu, tài khoản ngân hàng, token hoặc dữ liệu cá nhân thật.
